# Материалы защиты Zero-Spoiler

- `zero-spoiler.pptx` — редактируемая презентация, 8 слайдов, формат 16:9, заметки докладчиков.
- `zero-spoiler.pdf` — версия для просмотра и показа без PowerPoint.
- `pitch.md` / `pitch.pdf` — сценарий на двоих на 5 минут, короткий вариант на 3 минуты и ответы жюри.
- `pitch-solo.md` / `pitch-solo.pdf` — сценарий для одного выступающего на 5 минут, готовый короткий вариант на 3 минуты, действия для показа в одиночку и ответы жюри. Используются те же 8 слайдов; заметки внутри PowerPoint относятся к варианту на двоих.
- `assets/` — снимки настоящего интерфейса с демонстрационным прохождением, не результаты исследования.
- `generate.py` — воспроизводимая сборка материалов. Требуются Python, python-pptx, reportlab, Pillow и PyMuPDF; шрифты DejaVu Sans. Запуск: `python docs/presentation/generate.py`, затем `node scripts/sync-cloud-site.mjs`.

Просмотр с телефона: https://2-case.vercel.app/presentation.html. Страница показывает все слайды и полный текст выступления без отдельного приложения, входа и JavaScript. PDF и PPTX доступны по обычным ссылкам из `public/presentation/`. Генератор обновляет файлы для сайта вместе с исходными материалами.

Имена выступающих не указаны; «Девушка» и «Парень» — заменяемые обозначения. Содержание не заявляет подтверждённого эффекта обучения: реальный пилот ещё предстоит провести. QR-код ведёт на основной домен проекта.
