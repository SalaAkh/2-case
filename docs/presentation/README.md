# Материалы защиты Zero-Spoiler

- `zero-spoiler.pptx` — редактируемая презентация, 8 слайдов, формат 16:9, заметки докладчиков.
- `zero-spoiler.pdf` — версия для просмотра и показа без PowerPoint.
- `pitch.md` / `pitch.pdf` — сценарий на двоих на 5 минут, короткий вариант на 3 минуты и ответы жюри.
- `assets/` — снимки настоящего интерфейса с демонстрационным прохождением, не результаты исследования.
- `generate.py` — воспроизводимая сборка материалов. Требуются Python, python-pptx, reportlab и Pillow; шрифты DejaVu Sans. Запуск: `python docs/presentation/generate.py`.

Имена выступающих не указаны; «Девушка» и «Парень» — заменяемые обозначения. Содержание не заявляет подтверждённого эффекта обучения: реальный пилот ещё предстоит провести. QR-код ведёт на основной домен проекта.
