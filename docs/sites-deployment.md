## Продолжение после подключения исполняемого пакета Sites

1. Сохранить основной Next.js-проект и его команды запуска. Создать отдельный каталог хостинга из поставляемого Sites Vinext starter через `project-setup.mjs`.
2. Переиспользовать существующие `src/app`, компоненты, библиотеку и локальные файлы Monaco. Сохранить starter-интеграцию `sites()` и Worker entrypoint. Проверить совместимость серверных переменных окружения и пакета OpenAI с Worker runtime.
3. Создать один owner-private Site, немедленно сохранить возвращённый `project_id` в `.openai/hosting.json`. Не менять доступ на public.
4. Установить зависимости поддержанным helper. Выполнить проверки и сборку `build-site.mjs`, синхронизировать исходники через `site-workflow.mjs`. Сохранить адаптер и инструкции в этом репозитории.
5. Опубликовать точный архив и pushed commit через private deployment. Дождаться terminal status `succeeded` с фактическим HTTPS URL.
6. Проверить доступ владельца с телефона, `/api/status`, полный демодиалог (начало, ответ студента, три уровня подсказок) и отказ анализировать изменённый/произвольный код в демо. Не считать localhost, expected_url или служебный preview опубликованным сайтом.

## Секреты и деморежим

Ключ OpenAI не задан. Оставить `ENABLE_DEMO=true`; интерфейс и ответы должны явно объяснять: подготовленные диалоги работают только для трёх точных примеров, произвольный код не анализируется. Сохранить настоящий серверный OpenAI Responses API, генератор и независимую проверку, без подмены live-ответов демо.

Позже добавить `OPENAI_API_KEY` как **secret** в production runtime environment variables выбранного Sites-проекта (без чата, Git и hosting.json), затем повторно развернуть сохранённую версию для применения новой ревизии окружения. `OPENAI_MODEL` — `gpt-4.1-mini`, если модель доступна аккаунту. Для обычного Next.js локальный секрет задаётся в `.env.local` согласно README.

История остаётся в localStorage браузера и между устройствами не синхронизируется. Rate limit остаётся на экземпляр сервера. Код студента не выполняется.
