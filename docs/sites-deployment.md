# Размещение Zero-Spoiler Debugger

Сайт опубликован и проверен 5 ноября 2026 года: https://zero-spoiler-case-two.gladfloat4.chatgpt.site.

Доступ частный, только владельцу. На телефоне откройте ссылку и войдите через тот же аккаунт ChatGPT. Общедоступное размещение не включено.

## Проверенное состояние

- Основной Next.js-проект: 56 тестов, lint, TypeScript и production build проходят.
- Серверный адаптер Sites/Vinext: сборка и TypeScript проходят.
- Собранный Worker проверен HTTP-запросами: главная страница, локальный Monaco, `/api/status`, начало демодиалога, осмысленный ответ студента и все три уровня подсказок.
- На опубликованном сайте в браузере подтверждены вход владельца, редактор, демодиалог с контекстным ответом и три уровня подсказок. В консоли браузера ошибок не обнаружено. Мобильные вкладки проверены при ширине 390 px без горизонтального переполнения.
- Настоящие запросы OpenAI не проверены: ключ не задан. Демо явно обозначено, произвольный код в нём не анализируется.

## Исходники и обновление

Основное приложение находится в `src/`. `cloud-site/` содержит поддержанный Sites Vinext starter, адаптированный для существующих компонентов и серверных обработчиков. Обычные команды Next.js в корне сохранены.

После изменений в основном приложении выполните `node scripts/sync-cloud-site.mjs` из корня, затем установите зависимости адаптера при изменении package.json и выполните его проверки и сборку. Скрипт сохраняет инфраструктуру Sites и синхронизирует приложение из `src/`.

Для публикации следуйте Sites skill: используйте `build-site.mjs` и `site-workflow.mjs` из установленного пакета Sites, передавайте временный credential только через stdin и публикуйте точный архив с соответствующим pushed commit. В среде исполнения должен быть доступен пакет скриптов Sites; управляющие MCP-инструменты сами по себе его не устанавливают. Существующий адаптер уже сохранён в репозитории, повторно создавать starter не нужно.

Переиспользуйте `.openai/hosting.json` адаптера и существующий Site, не создавайте новый:

```text
project_id: appgprj_6aec00079c2881918e1e808424e3b3ac
deployment_id: appgdep_6aec02db989081918493e95e7a83f400
source commit: 7a5d2ac2bab536a411b1eb27f51d2745c3d73f63
```

Это коммит отдельного репозитория исходников Sites. Репозиторий пользователя `SalaAkh/2-case` содержит основной проект, адаптер и документацию.

## Настройка OpenAI

Добавьте `OPENAI_API_KEY` как секрет production runtime в настройках этого Sites-проекта, затем примените новую ревизию окружения повторным развёртыванием сохранённой версии. Не вставляйте ключ в чат, Git или hosting.json. `OPENAI_MODEL` по умолчанию — `gpt-4.1-mini`; доступ к модели и баланс API настраиваются отдельно. Ключ хранится на сервере, live-ответы проходят фильтр и независимую проверку.

Для обычного локального Next.js ключ указывается в `.env.local` согласно `.env.example`, затем сервер перезапускается. Для демо ключ не нужен. Его три сценария доступны через «Загрузить пример».

## Облачная разработка

Опубликована частная среда Codex Cloud `2-case`, привязанная к этому репозиторию. Установлены Node.js 24 и pnpm 11, сохранены инструкции установки и запуска, проверки выполнены в Linux. Чат для продолжения: `Zero-Spoiler Debugger — облако`.

Откройте Codex → Cloud под тем же аккаунтом и в том же рабочем пространстве. [Официальное руководство по облачным средам](https://learn.chatgpt.com/docs/environments/cloud-environments).

История учебных диалогов хранится в localStorage каждого браузера и между устройствами не синхронизируется. Rate limit действует на экземпляр сервера. Код студента не выполняется. Проверка ответов снижает риск спойлеров, но не является абсолютной гарантией.
